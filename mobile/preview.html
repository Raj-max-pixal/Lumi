📱 Lumi Mobile App

The developer social network — now as a fully functional React Native / Expo app.

  • 🏠 Home Feed with real-time posts & stories
  • 🔍 Explore grid with search & filters
  • ✨ AI Lab — 8 dev tools + chat assistant
  • 🚀 Hackathon project showcase
  • 💬 Real-time direct messaging
  • 👤 Developer profile with edit mode
  • 🎬 TikTok-style Dev Clips screen
  • 🔥 Same Firebase as web — same accounts!

🚀 Run on Your Phone

Install Expo Go from Play Store / App Store, then run:

cd d:\lumi\mobile
npx expo start --lan

Scan the QR code in the terminal with Expo Go. Your phone and PC must be on the same WiFi.

📦 Build APK

To build a standalone Android APK:

npx expo run:android
